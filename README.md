## Submission Checklist
- Make the GitHub repository public.
- Upload all project source code and phase documents.
- Keep the repository organized phase-wise.
- Add testing screenshots/evidence.
- Record the complete demo with voice-over.
- Upload the demo video to Google Drive.
- Set the Google Drive video permission to “Anyone with the link can view”.
- Add the GitHub and demo links to the final submission form, if required.

## Project Reference
The phase documents are based on the uploaded ComicCraft project document, which describes the FastAPI frontend/backend architecture, Gemini Flash/Pro story generation, Stable Diffusion image generation, layout building, PDF export, deployment, and testing workflow.
